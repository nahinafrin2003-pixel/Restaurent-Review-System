This project is a secure restaurant review system built with Laravel, designed to combine modern web application development with practical data protection. The platform allows users to register, log in, browse restaurants, submit reviews, and interact with review content in a user-friendly environment. What makes this project distinctive is its emphasis on security: sensitive user and review information is encrypted before being stored in the database and decrypted only when needed for use.

The system implements a custom cryptographic stack using asymmetric encryption techniques, including RSA and ECC, to protect different types of data. User-related fields such as email and contact information are encrypted using ECC, while review content is protected with RSA. In addition, the project uses HMAC-SHA256 to verify data integrity and ECC-based digital signatures to ensure authenticity and protect against tampering. These mechanisms are integrated directly into the application’s models and data flow, demonstrating a real-world use of cryptography in a full-stack web application.

Beyond security, the project also focuses on clean architecture and maintainability. It follows a structured Laravel-based development approach with models, controllers, services, and configuration layers that support scalability. The system reflects a strong understanding of secure software design, data handling, and backend development principles.

This project is especially suitable for showcasing skills in Laravel, PHP, web application development, cryptography, and secure system design. It demonstrates the ability to build a functional application while incorporating advanced security features that go beyond basic authentication and data storage.
